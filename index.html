Six layers, no magic.

Real lines from the playground source. Read top to bottom, the way a frame travels.

Input

Camera, mouse, and touch feed one loop. Camera frames lock near 30 FPS so tracking never starves render.

camera.read() // throttled near 30 FPS

Hand tracking

MediaPipe follows two hands at once, with smoothing, dead zones, and fist hysteresis against jitter.

hands.setOptions({ maxNumHands: 2 }) // line 1363

Target generation

Every form is computed at boot into plain arrays. One THREE.Points object holds all thirty five thousand.

const PARTICLE_COUNT = 35000 // line 819

Morph interpolation

Each frame every particle lerps toward its target. Morph speed is one number you can turn while it runs.

positions[i3] += (tx - positions[i3]) * morphSpeed // line 1573

Three.js rendering

Pixel ratio caps at 2 to protect the GPU on dense screens. Generated arrays in, light out.

renderer.setPixelRatio(Math.min(devicePixelRatio, 2)) // line 1252

Browser output

Interface polling ticks outside the render loop, twice a second. The deploy is static files on Vercel.

setInterval(poll, 500) // line 1988
